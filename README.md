<summary><b>🔍 SecureAI Gateway: under the hood</b></summary>

<br>

- **Multi-provider routing:** one OpenAI-compatible API in front of OpenAI, Google Gemini, and local Ollama, with real-time **SSE streaming**.
- **Gateway-owned API keys:** hashed in PostgreSQL, with **JWT auth** and **role-based access control** (admin/user), so provider keys never reach clients.
- **Rate limiting:** per-key **Redis Token Bucket** to prevent abuse and spam.
- **Response caching:** Redis-backed, to cut cost and latency on repeated queries.
- **Prompt Guard:** scans prompts and rejects malicious content with HTTP 400.
- **Observability:** logs model, provider, token counts, latency, and cost per request, with usage-summary APIs for analytics dashboards.
- **Deployment:** Docker Compose for local dev, Helm charts on k3d (NGINX ingress), one-command deploy via a bash script.

</details>
